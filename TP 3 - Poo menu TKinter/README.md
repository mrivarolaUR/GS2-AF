Ejercicio seleccionado: Juego de Adivinanza

Crea un juego de adivinanza de números donde el usuario tiene que adivinar un número aleatorio entre 1 y 100. El sistema debe dar pistas como "muy alto" o "muy bajo".

Componentes: Entry, Button, Label, Messagebox.

Objetivo: Generar números aleatorios y gestionar la interacción del usuario.
